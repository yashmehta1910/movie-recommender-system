
# 🎬 Movie Recommender System

A smart, interactive **Movie Recommendation System** built using **Python, Streamlit, and Machine Learning**.  
It suggests similar movies based on your selection using **Cosine Similarity** and **TMDB API** for posters and details.

---

## 🚀 Features
- 🔍 Search for any movie from the dataset  
- 🎥 Get top 5 similar movie recommendations instantly  
- 🖼️ Dynamic poster fetching from TMDB API  
- ⚡ Fast / slow mode for loading posters  
- 🔁 Auto-refreshing “Top Picks” section  
- 🎨 Netflix-style responsive UI using custom CSS  

---

## 🧩 Technologies Used
- **Python**
- **Streamlit**
- **Pandas / Scikit-learn**
- **Pickl**
- **Requests (TMDB API)**
